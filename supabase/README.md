# База данных Hatsit (Supabase)

В этой папке лежит копия всего, что есть в базе данных сайта. Всё это **уже применено** в рабочем проекте Supabase — запускать файлы заново не нужно. Папка нужна, чтобы код базы хранился рядом с кодом сайта и его можно было восстановить.

| Файл | Что внутри |
|---|---|
| `name_moderation.sql` | Проверка имён игроков (мат, ссылки, реклама) |
| `profiles.sql` | Профили игроков, рекорды, серии дней, оценки после игры |
| `profile_titles.sql` | Выбор титула в профиле |
| `mafia_online.sql` | Мафия онлайн: комнаты, правила, статистика, зрители |
| `app_stats.sql` | События сайта и страница статистики владельца (`/?stats=1`) |

## Если базу нужно создать с нуля

Откройте Supabase → SQL Editor и выполните файлы по порядку:

1. `name_moderation.sql`
2. `profiles.sql`
3. `profile_titles.sql`
4. `mafia_online.sql`
5. `app_stats.sql`

После этого задайте пароль страницы статистики (не короче 8 символов):

```sql
select set_stats_password('ваш пароль');
```

## Что сюда не входит

- Сами данные (профили игроков, оценки) — только структура.
- Ключи и пароли. Ключ Gemini хранится в Vercel → Settings → Environment Variables (`GEMINI_API_KEY`).
