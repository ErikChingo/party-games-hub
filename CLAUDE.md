## Как устроено

- **`index.html` — весь сайт в одном файле**: один `<script type="text/babel">` с React-кодом (React 18 и
  Tailwind подключаются с CDN). Редактировать нужно именно его.
- **`build.js`** (`npm run build`) компилирует JSX и минифицирует → `dist/index.html`. Vercel выкладывает `dist/`.
- **`api/`** — серверные функции Vercel (регион **sin1**, Сингапур — рядом с базой, см. `vercel.json`):
  - `cards.js` — судья онлайн-игр в Дурака, Блот, Блэкджек и Нарды (ходы, боты, таймеры, статистика).
  - `_lib/durak.js`, `_lib/blot.js`, `_lib/blackjack.js`, `_lib/nardy.js` — движки правил (Нарды: короткие и
    длинные, бот «лёгкий»/«средний»; ход отправляется целиком `{ type: "turn", steps }`).
  - `mafia-voice.js` — студийный голос ведущего Мафии (Gemini TTS, кеш в Supabase Storage).
  - `mafia-story.js` — короткие «истории ведущего» после ночи (Gemini).
  - `ai-chat.js` — чат помощи на сайте. **В его промпте описаны все функции сайта — при каждом новом
    функционале его нужно дописывать.**
  - `support-ticket.js` (Discord), `health.js`.
  - Переменные окружения в Vercel: `GEMINI_API_KEY`, `SUPABASE_SERVICE_ROLE_KEY` (от интеграции Supabase),
    `DISCORD_WEBHOOK_URL`, необязательные `GEMINI_*` для смены моделей.
- **Supabase** (проект `zocoaqqcrxpbkyzlfzsf`, регион ap-southeast-1): профили и рейтинг, Мафия онлайн
  (функции `mafia_*`), Бункер/Суд (Realtime), открытые комнаты, карточные комнаты `card_rooms`, статистика сайта.
  Папка `supabase/` — записи того, что применено в базе (`cards.sql` — всё про карточные игры).
- **`sw.js`** — service worker (офлайн-кеш оболочки). `manifest.json`, иконки, `robots.txt`, `sitemap.xml`.

### Важные места в `index.html` (искать по имени)

- `I18N` — все тексты. **Каждый текст — сразу на трёх языках: `ru`, `en`, `hy`.** Армянские тексты носителем
  языка пока не вычитаны.
- `GAMES` — список игр на главном экране (`section: "cards"` → раздел «Карточные»), `hubGameOrder`, `Hub`.
- `reducer` (действия `OPEN_*`), `SCREEN_COMPONENTS` — какой экран у какой игры.
- `ACHIEVEMENTS`, `PLAYER_TITLES`, `TITLE_PROFILE_FIELDS`, `LEADERBOARD_TABS`, `ProfilePanel` — достижения,
  титулы, рейтинг. Новый титул нужно добавить ещё и в серверную `set_selected_title` (см. `supabase/cards.sql`).
- `useLeaveGuard`, `confirmLeave` — защита от случайного выхода из игры (двойное «назад»).
- Онлайн-игры: `useMafiaRoom` (Мафия, RPC `mafia_*`), Бункер/Суд (Realtime, хост держит игру, передача хоста),
  `useCardRoom(game, predict, sessionKey)` (Дурак/Блот/Блэкджек через `/api/cards`; свой ход показывается сразу
  через `durakPredict`/`blotPredict`/`blackjackPredict`, ответ сервера его заменяет).
- `NardyApp`, `NardyTable`, `NardyBoard` (доска SVG, всегда с точки зрения смотрящего: его дом справа внизу).
- `DurakApp`, `BlotApp`, `BlackjackApp` и их столы; `CardFace`/`DurakCard`/`DurakCardBack` — рисунки карт (SVG).
  Буквы на картах: русский В Д К Т, английский J Q K A, армянский — как русский.

## Правила, о которые уже спотыкались

- **Хуки React никогда не вызывать внутри условий/веток JSX** (была ошибка React #300: `useRules()` внутри меню
  Дурака). Есть тест, что приложения карточных игр вызывают одинаковое число хуков на любом экране.
- **Движки карточных игр живут в двух местах**: `api/_lib/*.js` (сервер) и их точная копия внутри `index.html`
  между маркерами `/* DURAK-ENGINE-BEGIN */ … END` (и BLOT, BLACKJACK, NARDY). Править только `api/_lib/*.js`, потом
  `node dev/sync-engines.js`. Тесты проверяют, что копии совпадают.
- Скрытое от игроков (колода, закрытая карта дилера, чужие руки, `secretHash`, `profileId`) никогда не должно
  попадать в ответы: в движках это `viewFor()`, в базе — `cards_view()`.
- Достижения карточных игр — **только онлайн и только если в партии было хотя бы 2 человека** (решение Эрика).
  Считает сервер (`statsEvents` в `api/cards.js` → `cards_record()` в базе).
- В SQL-проверках на живой базе: всё внутри `do $$ … raise exception 'ALL_PASSED_ROLLBACK' $$`, чтобы ничего не
  осталось; не использовать слово DELETE; не делать `pg_sleep` после вызовов `mafia_*`.
- Задержка онлайн-игр: база в Сингапуре, поэтому функции Vercel тоже в `sin1` (ход ~0,35 с из Еревана).

## Сборка и проверки

```bash
npm install            # в корне: esbuild + typescript для сборки
npm run build          # index.html -> dist/index.html
cd dev
npm install            # react / react-dom для тестов
npm test               # все наборы тестов (около 10–15 минут); быстрее: node run-all.js durak
node sync-engines.js   # после правок в api/_lib/*.js
```

- `dev/tests/` — ~35 наборов: движки (тысячи партий ботов), сервер `/api/cards` с поддельной базой в памяти,
  интерфейс (рендер компонентов, хуки, онлайн-игра двумя «телефонами» через настоящий обработчик), голос Мафии,
  достижения и т. д. `static_check.js` — синтаксис сборки, дубли объявлений, пропущенные ключи I18N.
- Тесты загружают собранный `dist/index.html` — **перед тестами всегда `npm run build`**.
- Внешний вид в тестах не проверяется (Tailwind грузится с CDN). Вид — глазами на живом сайте или в браузере.
